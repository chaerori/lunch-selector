## 추가 출처

`rice.svg`(한식·기본 아이콘)와 앱 아이콘(`favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`)에는
[Streamline](https://streamlinehq.com)의 **Streamline Color** 세트 중 `serving-dome-flat`을 사용했습니다.

- 저작자: Streamline
- 라이선스: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
